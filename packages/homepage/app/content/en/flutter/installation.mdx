Install the package from pub.dev:

```sh
flutter pub add tinyrack_ui
```

`tinyrack_ui` 0.1.0 requires Flutter 3.44 or later and Dart 3.12 or later.
Import the public library from `package:tinyrack_ui/tinyrack_ui.dart`. The
package includes IBM Plex Sans, Mono, Korean, and Japanese font assets, so no
runtime font download is required.

The example application supports Android, iOS, web, Windows, macOS, and Linux.
Run `flutter run` from the application that consumes the package to use the
platform selected by Flutter.

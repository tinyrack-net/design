pub.dev에서 패키지를 설치해요.

```sh
flutter pub add tinyrack_ui
```

`tinyrack_ui` 0.50.0은 Flutter 3.44 이상과 Dart 3.12 이상이 필요해요.
`package:tinyrack_ui/tinyrack_ui.dart`에서 공개 라이브러리를 가져오세요.
IBM Plex Sans, Mono, 한글, 일본어 글꼴 에셋이 패키지에 들어 있어 실행 중에
글꼴을 내려받지 않아요.

예제 앱은 Android, iOS, web, Windows, macOS, Linux를 지원해요. 패키지를
사용하는 앱에서 `flutter run`을 실행하면 Flutter가 선택한 플랫폼에서
확인할 수 있어요.

## CI에서 디자인 시스템 강제하기

같은 패키지에 포함된 검사기를 실행하세요.

```sh
dart run tinyrack_ui:tinyrack_ui_check
dart run tinyrack_ui:tinyrack_ui_check --format=github
```

기본적으로 `lib`의 제품 Dart 파일을 검사하고 시각 원시 값, Tinyrack 비공개 경로,
공개 TR 컴포넌트로 바꿀 수 있는 Material 컨트롤, 빠진 밝은·어두운 Tinyrack 테마
설정을 위반으로 처리해요. 공개 TR 토큰에서 파생한 상수와 0, 전체 확장, 실행 중에
결정되는 크기, 비율 같은 구조적 값은 사용할 수 있어요. 위반이 있으면 종료 코드
`1`, 설정이나 소스를 해석할 수 없으면 `2`를 반환해요. 기본 경로는
`tinyrack.check.json`으로 바꿀 수 있으며 baseline 모드는 제공하지 않아요.

불가피한 구조적 예외에는 규칙 하나와 안전한 이유를 함께 적으세요.

```dart
// tinyrack-check-ignore-next-line tokens/no-literal -- 좌표는 문서 데이터에서 결정돼요
final inset = EdgeInsets.only(left: 20);
```

## 터미널 앱

`tinyrack_ui` 0.36.0부터 터미널 에뮬레이터를 제공하지 않아요.
`tinyrack-net/flutter-packages/packages/termworld`의 `termworld`를 정확한 커밋에
고정해 직접 추가하세요. 제품 레이어에서 Tinyrack의 색상, 타이포그래피, 간격,
커서, 포커스, 선택 토큰을 `TerminalView`에 전달해요. `TRTerminalView` 호환
어댑터는 제공하지 않아요.

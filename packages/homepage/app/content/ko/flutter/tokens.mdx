JSON 토큰 원천에서 웹 CSS와 Flutter 값을 함께 생성해요. 숫자를 복사하지
말고 공개 토큰 클래스를 사용하세요.

```dart
Padding(
  padding: const EdgeInsets.all(TRSpacing.medium),
  child: DecoratedBox(
    decoration: const BoxDecoration(
      borderRadius: BorderRadius.all(TRRadii.medium),
      boxShadow: [TRShadows.raised],
    ),
    child: Text('랙', style: TRTypography.body),
  ),
);
```

`TRSpacing`, `TRRadii`, `TRTypography`, `TRMotion`, `TRShadows`에는
플랫폼에 맞게 변환한 값이 들어 있어요. CSS 전용 단위와 그림자 문법은
생성기가 변환하며, 지원하지 않는 변환이 있으면 토큰 일치 검사가 실패해요.

## 레이아웃 폭

`TRBreakpoints`에는 레이아웃의 형태가 바뀌는 뷰포트 폭이, `TRMeasurements`에는
그 안에 놓이는 영역의 폭이 들어 있어요. 두 값을 모두 토큰에서 읽으면 같은 앱의
두 화면이 서로 다른 폭에서 재배치되는 일을 막을 수 있어요.

```dart
LayoutBuilder(
  builder: (context, constraints) => constraints.maxWidth < TRBreakpoints.medium
      ? detail
      : Row(
          children: [
            SizedBox(width: TRMeasurements.paneMd, child: list),
            Expanded(child: detail),
          ],
        ),
);
```

무엇의 크기를 정하는지에 맞는 값을 고르세요. `paneSm`과 `paneMd`는 내비게이션
레일이나 목록-상세 레이아웃의 목록 쪽처럼 구조를 이루는 영역의 폭이에요.
`readingWidthSm`부터 `readingWidthLg`까지는 콘텐츠 열의 최대 폭을 제한해서,
넓은 창에서도 설명과 컨트롤이 멀어지지 않게 해요. `measure` 스케일은 텍스트
한 덩어리의 폭이고, `TRControlMetrics`는 컨트롤 하나의 크기예요.

## 핵심 속성

`TRInput`은 네이티브 `<input>`을 렌더링하며 속성, ref, 이벤트, 유효성과 폼 동작을 보존해요. `TRField.Root`으로 감싸고 `TRField.Label`을 함께 두세요. 필드가 레이블과 입력을 연결하므로 `id`나 `htmlFor`를 직접 쓰지 않아도 돼요. 안내는 `TRField.Description`, 검증 메시지는 `TRField.Error`로 작성하면 필드가 `aria-describedby`로 연결해요.

밀도가 높은 컨트롤에는 `uiSize="sm"`, 일반 폼에는 기본값인 `md`, 더 큰 조작 영역이 필요할 때는 `lg`를 쓰세요. `disabled`, `readOnly`, `required`는 네이티브 의미와 Tinyrack 상태 스타일을 유지해요. 필드 전체 상태는 `TRField.Root`의 `disabled`나 `invalid`로 지정하고, 감싸는 필드가 없을 때만 입력에 `aria-invalid`를 두세요.

  title="필수 제출과 복구"

import { TRField } from '@tinyrack/ui/components/field';
import { TRForm } from '@tinyrack/ui/components/form';
import { TRInput } from '@tinyrack/ui/components/input';
import { useRef, useState } from 'react';

export function RequiredInput() {
  const inputRef = useRef<HTMLInputElement>(null);
  const [attempted, setAttempted] = useState(false);
  const [submitted, setSubmitted] = useState(false);
  const [value, setValue] = useState('');
  const invalid = attempted && value.trim().length === 0;

  return (
    <TRForm
      noValidate
      onSubmit={(event) => {
        event.preventDefault();
        const valid = event.currentTarget.checkValidity();
        setAttempted(true);
        setSubmitted(valid);
        if (!valid) inputRef.current?.focus();
      }}
    >
      <TRField.Root invalid={invalid}>
        <TRField.Label>랙 이름</TRField.Label>
        <TRInput
          name="rack"
          onValueChange={(nextValue) => {
            setValue(nextValue);
            setSubmitted(false);
          }}
          onInvalid={(event) => event.preventDefault()}
          ref={inputRef}
          required
          value={value}
        />
        {invalid ? <TRField.Error match>랙 이름을 입력하세요.</TRField.Error> : null}
      </TRField.Root>
      <TRButton type="submit">계속</TRButton>
      <output aria-live="polite">
        {submitted ? value + ' 생성 준비 완료' : ''}
      </output>
    </TRForm>
  );
}` ,
      styles: { code: "@import '@tinyrack/ui/components/button.css';\n@import '@tinyrack/ui/components/field.css';\n@import '@tinyrack/ui/components/form.css';\n@import '@tinyrack/ui/components/input.css';" },
    },
  ]}
/>

## API

`TRInputProps`는 Base UI Input 속성을 확장하고 기본값이 `md`인 `uiSize?: 'sm' | 'md' | 'lg'`를 추가해요. `name`, `type`, `autoComplete`, `disabled`, `readOnly`, `required` 같은 네이티브 입력 속성과 `ref`, `className`, `style`, 이벤트 핸들러를 전달해요.

제어된 텍스트에는 `value`와 `onValueChange(value, details)`를 함께 사용하고, 네이티브 비제어 및 폼 초기화 동작에는 `defaultValue`를 사용하세요. 이벤트 객체가 필요하면 네이티브 `onChange`를 사용하세요. `aria-invalid="true"`, Base UI의 `data-invalid`, 네이티브 `:invalid`는 모두 잘못된 값의 테두리를 활성화해요. `render` 속성은 렌더링 요소를 교체하며 Base UI가 동작, 상태, ref, `.tr-input` 스타일을 병합해요.
